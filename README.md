An entry for make.fun's [The Long Roast](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) bounty: one satirical sentence about lawmakers who regulate AI, crypto or the internet but cannot convert a file to PDF.

`main.ts` (Node 22, standard library only) writes the sentence to `/output/entry.txt`. The output is the same bytes on every run.

```
node main.ts && cat /output/entry.txt
```
